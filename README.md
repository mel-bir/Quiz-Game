# 🧠 JavaScript Quiz Game

A clean, interactive multiple-choice quiz game built with vanilla HTML, CSS, and JavaScript. Users can test their knowledge, receive instant visual feedback on their answers, and view their final score at the end of the round.

🔗 **Live Demo:** [View Live Project](https://github.com/mel-bir/Quiz-Game.git)
---

## ✨ Features

- **Dynamic Question Rendering:** Loads questions and multiple-choice options dynamically into the DOM.
- **Instant Answer Feedback:** Highlights correct and incorrect answers immediately upon selection.
- **Real-Time Score Tracking:** Calculates and displays the user's final score and accuracy at the end of the quiz.
- **Restart Functionality:** Allows players to reset the game state and play again without refreshing the page.
- **Responsive Design:** Adapts cleanly across desktop, tablet, and mobile viewports.

---

## 🛠️ Built With

- **HTML5** – Semantic markup for accessible structure
- **CSS3** – Flexbox/Grid layout, custom properties (variables), and state transitions
- **JavaScript (ES6+)** – DOM manipulation, event handling, and game state logic
